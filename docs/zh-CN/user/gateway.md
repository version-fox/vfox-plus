# 网关（Docker）

> [English](../../en/user/gateway.md)

Docker 镜像不是装在容器里的 vfox-plus：它没有 vfox、没有窗口，也没有自己的 SDK，并且不接受任何
参数。它是一个**网关**。和[安卓 App](android.md) 一样，它连接某台电脑上运行着的一个 vfox-plus（已开启
网页界面和*其他设备*，见[网页界面与其他设备](remote.md)），再把那个 vfox-plus 的界面显示给你与网关配对的
浏览器。用它可以把界面放在你选定的地址上，比如放在浏览器能到达、手机却到不了的容器主机上。

镜像暂未发布。从仓库构建，并映射端口运行：

```sh
docker build -f mygo/Dockerfile -t vfox-plus-gateway mygo
docker run --rm -p 8080:8080 -v vfox-plus-gateway:/home/vfoxplus/.config/vfox-plus-gateway vfox-plus-gateway
```

卷用来在两次运行之间保存网关记住的东西：它所配对的 vfox-plus、在那里的会话，以及网关自己的证书。
没有卷，每次新建容器，网关都从零开始。

1. **把浏览器与网关配对。** 网关会打印（用 `docker logs` 查看）自己证书的 SHA-256 指纹，以及一个
   一次性链接，形如 `https://localhost:8080/auth/connect/…`。把 `localhost` 换成能到达容器的地址，
   在浏览器里打开。网关用自己生成的证书提供 HTTPS，所以浏览器会给出警告：继续之前，先把浏览器
   显示的指纹与打印出来的核对。链接一次性有效，五分钟后过期；重启容器会得到新的，它是日志里最后
   一个。

   还没有配对的浏览器看到的是网关的页面，上面也显示这个指纹：

   ![浏览器还没有配对时看到的网关页面，上面有网关证书的指纹](https://iili.io/niyLhua.png)

2. **把网关与 vfox-plus 配对。** 网关的页面上有一个输入框，用来粘贴 vfox-plus 的配对链接。在 PC 上
   依次选择*设置 → 网页界面 → 配对手机 → 显示二维码 → 复制链接*，再粘贴到那里。网关随后会显示
   vfox-plus 证书的指纹：与 vfox-plus 设置里的（*证书*）核对，然后选择*一致，信任并配对*。此后网关
   只信任这一个证书，如果这个地址上的证书变了，会带着警告再次询问。证书若是由机构签发的，则无需
   核对。

   | 还没有与任何 vfox-plus 配对的网关页面 | 粘贴了 vfox-plus 的链接 |
   | --- | --- |
   | ![网关还没有配对任何 vfox-plus，页面上有粘贴链接的输入框](https://iili.io/niyLeGp.png) | ![粘贴了 vfox-plus 配对链接的输入框](https://iili.io/niyLbS9.png) |

   ![要求把 vfox-plus 证书的指纹与它设置里的核对的页面](https://iili.io/niyQWf2.png)

3. **使用。** 浏览器会被带到 vfox-plus 的界面：与配对浏览器看到的相同，由那个 vfox-plus 自己提供，
   所以页面总与正在运行的版本相符。在网关的页面上用*配对另一个浏览器*配对更多浏览器；粘贴另一个
   vfox-plus 的链接，就把网关配对给它（*忘记此 vfox+* 则放掉现在的这个）。

   | 通过网关看到的 vfox-plus 界面 | 配对之后的网关页面 |
   | --- | --- |
   | ![浏览器里通过网关提供的 vfox-plus 界面](https://iili.io/niyQp0N.png) | ![配对之后的网关页面：vfox-plus 的地址与它信任的证书](https://iili.io/niyZIee.png) |

网关在 vfox-plus 那里的会话和手机的一样最长一天，网关运行期间每隔几小时就续期一次。vfox-plus 退出
或重新启动时，它的会话都会结束：网关页面会这样告诉你，你再粘贴一个新链接。vfox-plus 没有运行时，
界面会提示连不上它。

须知：

- **同一台电脑上的 vfox-plus。** 其他设备用的链接在容器里能用：它是这台 PC 在网络上的地址。
  *在浏览器中打开*的链接（`http://127.0.0.1:…`）粘贴到网关里，指的是容器自己。在 Linux 上，改用
  `--network host` 代替 `-p` 运行容器，才能到达这台电脑的回环地址；这时网关监听这台电脑的 8080
  端口。
- **自己的证书。** 把浏览器信任的证书放进卷里，命名为 `cert.pem` 和 `key.pem`（PEM 文件），网关
  就用它提供服务，不再自己生成。
- **谁可以使用。** 与网关配对的浏览器拥有所配对的 vfox-plus 的全部界面，和已配对的手机一样，还可以
  让网关去连接容器能到达的任何地址（网关就是这样与 vfox-plus 配对的）。网关把它在 vfox-plus 那里的
  会话保存在卷里，文件只有它的用户可读：保管这个卷要像保管密码一样。容器的日志里有配对浏览器的
  链接，所以能读日志的人就能配对一个浏览器。
- **端口。** 容器内的端口是 8080，映射成什么都行（`-p 9443:8080`），并在主机的防火墙里放行。
