# 其他设备与轻量模式

> [English](../../en/user/remote.md)

vfox-plus 是桌面应用，没有命令行：像其他应用一样启动它，它还做什么，由设置决定。本页讲其中
三项，都在*设置 → 其他设备*里：是否允许其他设备连接、轻量模式，以及其他设备如何连到 vfox-plus。

vfox-plus 不在这台电脑上提供网页界面。其他设备通过[网关](gateway.md)看到它：网关是一个 Docker 镜像，
把界面提供给与它配对的浏览器；手机则用[手机端 App](android.md)。

## 其他设备

开启*其他设备*并确认，网关或手机就能与 vfox-plus 配对。它默认关闭：这会把 vfox-plus 开放给网络，
所以只在你信任的网络里允许。

| 先弹出的询问 | 允许之后设置里显示的内容 |
| --- | --- |
| ![询问是否允许其他设备连接](https://iili.io/nyiVT2n.png) | ![允许其他设备之后的设置：端口、给手机配对的二维码与证书](https://iili.io/nyiVlBS.png) |

- vfox-plus 监听设置里显示的**端口**，默认 8369，可以修改。这台电脑的防火墙需要放行它。
- 出了自己的网络，vfox-plus 只有在别处发布它时才可达：反向代理、隧道，或者[网关](gateway.md)。
  把这个地址（例如 `https://vfox.example.com`）填进**公网地址**，配对链接与二维码就会用它，
  而不是这台电脑在网络上的地址，不在家里的手机也能配对。不填时链接写的是这台电脑在网络上的地址，
  只有同一网络里的手机才连得上。
- 其他设备通过 **HTTPS** 连接。没有你自己的证书时，vfox-plus 自己生成并自己签名，设置里显示它的
  SHA-256 指纹：信任之前，先和浏览器、网关或手机端 App 里显示的指纹核对。要用自己的证书，选择
  *证书 → 浏览…*，再选证书与它的私钥（PEM 文件）。
- *配对手机*显示配对链接的**二维码**。用[手机端 App](android.md)拍下二维码（或选它的图片）来读取，也可以把链接粘贴到[手机端 App](android.md)或[网关](gateway.md)里；
  链接就显示在二维码下面，点*复制链接*即可复制；证书指纹在设置里的*证书*一项中，供要核对的人看。电脑接在
  不止一个网络上、或设了公网地址时，二维码下方会列出每个地址，选手机能到达的那个。链接一次性有效，
  五分钟后过期。
- 已配对的设备会话保持 24 小时。关闭*其他设备*或关闭 vfox-plus，会立即断开所有这些连接，之后
  需要重新配对。

| 在电脑上，*配对手机*显示的二维码与链接 | 界面设置里，同样的二维码 |
| --- | --- |
| ![在 vfox-plus 的窗口里，给手机配对的二维码与链接](https://iili.io/nyiVWpj.png) | ![界面的设置里，给手机配对的二维码](https://iili.io/nmiRBSe.png) |

界面的设置里有同样的开关，手机端 App 的设置里也一样：在已配对的浏览器或手机上就能允许其他设备、修改端口、开关轻量模式，
*配对手机*在那里也会显示二维码——没有窗口的电脑（轻量模式）就是这样给手机配对的。

![已配对的界面设置里的连接卡片，在手机上](https://iili.io/nmDwt5P.png)

## 发布到互联网

在家里，其他设备通过这台电脑在网络上的地址连接，同一 Wi-Fi 下的手机足够用。出了这个网络，
它需要一个互联网上的地址，而 vfox-plus 自己不运行中继：地址来自某个把它发布出去的东西。

- **自己的隧道。** 把反向代理、隧道或[网关](gateway.md)发布出来的地址填进**公网地址**，
  配对链接与二维码就会用它。
- **自带的开关。***公网隧道*用免费的
  [Cloudflare 快速隧道](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/do-more-with-tunnels/trycloudflare/)
  发布 vfox-plus：无需账号、无需配置，一个开关。还没有安装时，开启会从 Cloudflare 的 GitHub
  发布页下载隧道程序（约 50 MB）并校验 SHA-256。地址是随机的，例如
  `https://one-two-three.trycloudflare.com`，每次启动都会变。关闭开关或退出 vfox+ 就结束。

隧道会让连进来的网关、手机与其他设备经过 Cloudflare；快速隧道面向短时使用，不承诺可用性。
保护 vfox-plus 的是配对：设备仍需要一次性链接，会话保持 24 小时。

## 轻量模式

关闭窗口会退出 vfox-plus，其他设备的连接也随之结束。开启*轻量模式*（需要先允许其他设备）后，
关闭窗口时 vfox-plus 不退出，只是没有窗口：网关与正在使用它的手机保持连接，运行中的任务也继续执行。

- **恢复窗口**：vfox-plus 没有窗口时会在托盘里放一个图标，在它的菜单里选*打开 vfox+*即可。像往常
  一样从启动器再次启动 vfox-plus 也一样，而且没有托盘也能用：不会再起第二个 vfox-plus，已在运行
  的那个打开它的窗口，新启动的随即结束。
- **彻底结束**：托盘图标的菜单里有*退出 vfox+*；窗口的设置里，轻量模式开启时也会出现
  （*设置 → 其他设备 → 退出 vfox+*）。退出会取消运行中的任务。从系统里结束进程同样会退出它。

关闭窗口会释放窗口占用的东西，但 vfox-plus 仍是桌面应用：窗口所用的界面库仍留在内存里，所以只
少用几 MB，而不是几十 MB。

### 托盘图标

图标只在没有窗口时显示，窗口打开就消失，所以带着窗口的 vfox-plus 没有图标。它面向 vfox-plus 为之开发并测试的
两种桌面：

- **Windows 11。**在任务栏的通知区域，与其他图标在一起。点击图标恢复窗口，右键打开菜单。
- **GNOME**，Ubuntu 的桌面。在顶部的面板里，由它的 AppIndicator 扩展显示这类图标：Ubuntu 默认启用它，
  其他发行版把它做成软件包 `gnome-shell-extension-appindicator`。点击图标显示菜单。

其他桌面不受支持。KDE Plasma 和托盘是旧式的桌面，vfox-plus 不保证有图标：请使用 GNOME。没有图标时，其他
一切照旧：vfox-plus 仍像以前一样无窗口运行，再次启动 vfox-plus 就能恢复窗口。
