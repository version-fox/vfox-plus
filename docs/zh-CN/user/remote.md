# 网页界面、其他设备与安卓

> [English](../../en/user/remote.md)

vfox-plus 是桌面应用，没有命令行：像其他应用一样启动它，它还做什么，由设置决定。本页讲其中
三项，都在*设置 → 网页界面*里：网页界面、轻量模式，以及可以连接的其他设备。

## 网页界面

开启*网页界面*后，vfox-plus 在运行期间向本机的浏览器提供它的界面。该项会写明地址：只在本机
有效，比如 `http://127.0.0.1:41233`，其他电脑连不上。选择*在浏览器中打开*，浏览器就会用一次性
链接配对并打开它。链接一次性有效，五分钟后过期；*复制链接*另外生成一个放进剪贴板。

配对后的浏览器得到完整界面：已安装 SDK 的安装/卸载/使用、插件仓库的添加/更新/移除、带实时
进度与日志的任务、以及设置。vfox-java、vfox-nodejs 与 vfox-flutter 这三个插件提供的功能一应
俱全，和桌面应用一样：Java 要列出的发行版、筛选 Chip、按名称安装，以及带下载镜像的选项页（见
[Java、Node.js 与 Flutter](using.md#javanodejs-与-flutter)）。安卓应用显示的是同一个界面。

| ![配对后的 Web 界面](https://iili.io/n87KTiu.png) | ![配对后的 Web 界面里 Java 的发行版与 Chip](https://iili.io/n8eIQMG.png) |

Chrome 和 Edge 可以把配对后的界面安装为应用，有独立的窗口和 vfox+ 图标（地址栏里的安装
按钮，或菜单里的“安装”）。浏览器在本机上、以及在它信任其证书的 HTTPS 下才会提供，vfox-plus
自己生成的证书不行。重启 vfox-plus 后配对不会保留：已安装的应用显示配对页时，再到设置里选择
*在浏览器中打开*即可。

网页界面只能在窗口里开关。已配对的浏览器或手机不能，因为那会断开它正在用的连接。

## 轻量模式

关闭窗口会退出 vfox-plus，网页界面也随之结束。开启*轻量模式*（需要先开启网页界面）后，关闭
窗口时 vfox-plus 不退出，只是没有窗口：网页界面继续为正在使用它的浏览器和手机服务，运行中的
任务也继续执行。

- **恢复窗口**：vfox-plus 没有窗口时会在托盘里放一个图标，在它的菜单里选*打开 vfox+*即可。像往常
  一样从启动器再次启动 vfox-plus 也一样，而且没有托盘也能用：不会再起第二个 vfox-plus，已在运行
  的那个打开它的窗口，新启动的随即结束。
- **打开网页界面**：在同一个菜单里选*打开网页界面*，在本机浏览器中打开。
- **彻底结束**：托盘图标的菜单里有*退出 vfox+*；窗口的设置里，轻量模式开启时也会出现；或在已配对
  的浏览器或手机上（*设置 → 连接 → 退出 vfox+*）。退出会取消运行中的任务。从系统里结束进程同样
  会退出它。

关闭窗口会释放窗口占用的东西，但 vfox-plus 仍是桌面应用：窗口所用的界面库仍留在内存里，所以只
少用几 MB，而不是几十 MB。

### 托盘图标

图标只在没有窗口时显示，窗口打开就消失，所以带着窗口的 vfox-plus 没有图标。它面向 vfox-plus 为之开发并测试的
两种桌面：

- **Windows 11。**在任务栏的通知区域，与其他图标在一起。点击图标恢复窗口，右键打开菜单。
- **GNOME**，Ubuntu 的桌面。在顶部的面板里，由它的 AppIndicator 扩展显示这类图标：Ubuntu 默认启用它，
  其他发行版把它做成软件包 `gnome-shell-extension-appindicator`。点击图标显示菜单。它还需要库
  `libayatana-appindicator3`：vfox-plus 的软件包推荐安装它，所以通常会一并装上；若安装时跳过了推荐包，
  之后可用 `sudo apt install libayatana-appindicator3-1` 补上。

其他桌面不受支持。KDE Plasma 和托盘是旧式的桌面，vfox-plus 不保证有图标：请使用 GNOME。没有图标时，其他
一切照旧：vfox-plus 仍像以前一样无窗口运行，再次启动 vfox-plus 就能恢复窗口，也可以用浏览器。

## 其他设备

手机或另一台电脑也能用网页界面。开启*其他设备*（需要先开启网页界面）并确认。它默认关闭：这会
把 vfox-plus 开放给网络，所以只在你信任的网络里允许。

- vfox-plus 监听设置里显示的**端口**，默认 8369，可以修改。这台电脑的防火墙需要放行它。
- 其他设备通过 **HTTPS** 连接。没有你自己的证书时，vfox-plus 自己生成并自己签名，设置里显示它的
  SHA-256 指纹：信任之前，先和浏览器或安卓应用里显示的指纹核对。要用自己的证书，选择
  *证书 → 浏览…*，再选证书与它的私钥（PEM 文件）。
- *配对手机*显示配对链接的**二维码**和链接本身。电脑接在不止一个网络上时有不止一个地址：选手机
  能到达的那个。用[安卓应用](#安卓-app)扫描二维码，或在另一台电脑的浏览器里打开链接。链接一次性
  有效，五分钟后过期。
- 已配对的设备会话保持 24 小时。关闭*其他设备*或关闭 vfox-plus，会立即断开所有这些连接，之后
  需要重新配对。

网页界面的设置里有同样的开关：在已配对的浏览器或手机上就能允许其他设备、修改端口、开关轻量
模式，*配对手机*在那里也会显示二维码——没有窗口的电脑（轻量模式）就是这样给手机配对的。

## 安卓 App

安卓 App 用手机操控 PC 上的 vfox-plus：界面与上述配对浏览器相同。界面里指向其他网站的链接
（插件主页、插件文档）会在手机的浏览器里打开。

1. 在 PC 上打开 vfox-plus，进入*设置 → 网页界面*，开启网页界面和*其他设备*。在 PC 的防火墙里放行
   该端口。
2. 在手机上安装 `vfox-plus-android` 产物的 `.apk` 并打开。
3. 在 PC 上点*配对手机*旁的*显示二维码*，用 App 扫描二维码，或复制链接粘贴进 App，然后连接。
   如果 PC 用的是它自己生成的证书，App 会显示它的指纹：接受前先与 PC 设置里的指纹核对，和浏览器里
   一样。
4. App 保持配对，同一网络下自动重连。配对过期，或 PC 上的 vfox-plus 重启过，就扫描新的二维码。

App 打开时是配对界面：扫描 PC 上的二维码（安卓会请求一次相机权限）或粘贴链接。自签名证书会先显示
它的指纹，用来与 PC 上的核对。
