# 国际化

> [English](../../en/dev/i18n.md)

vfox-plus 提供**英文**和**简体中文**。应用处处使用同一套翻译目录，措辞一致，
每条文本只翻译一次。

## 目录

目录在 [`shared/i18n`](../../../shared/i18n)，采用
[Application Resource Bundle](https://github.com/google/app-resource-bundle)
格式：消息使用 [ICU MessageFormat](https://unicode-org.github.io/icu/userguide/format_parse/messages/)
的 JSON 文件。

| 文件 | 区域 | 职责 |
| --- | --- | --- |
| `app_en.arb` | `en` | 模板：每条消息及其元数据。 |
| `app_zh.arb` | `zh`（简体中文，`zh-Hans`） | 译文。 |

`app_zh.arb` 用通用 `zh` 编码，因为它是唯一的中文目录；若加繁体中文则为
`app_zh_Hant.arb`，`app_zh.arb` 继续作为所有中文区域的回退。

模板中的消息形如：

```json
"sdksVersionCount": "{count, plural, =0{No version installed} =1{1 version installed} other{{count} versions installed}}",
"@sdksVersionCount": {
  "description": "Number of installed versions of an SDK.",
  "placeholders": { "count": { "type": "int", "example": "3" } }
}
```

规则：

- 键为 `lowerCamelCase`，按所属区域开头（`nav…`、`home…`、`sdks…`、`sdk…`、
  `version…`、`available…`、`plugins…`、`task…`、`settings…`、`config…`、
  `about…`、`action…`）。
- 模板每条消息都有 `description`，每个占位符都有 `type` 与 `example`。
- 复数与选择用 ICU 语法；不拼接翻译片段。
- 撇号起引用作用，同 ICU：要在 `{`、`}` 或 `#` 前显示撇号，写两个（`''`）；
  其它位置（`don't`）就是撇号。作为参数的数字按语言习惯书写（`1,234`）。
- 译文保留模板的每个占位符。
- 不翻译的文本（如语言名 `English`、`简体中文`、命令 `vfox activate`、文件名）
  不进目录。

core i18n 包的单元测试（`mygo/core/i18n`，解析目录并格式化 ICU 消息）检查这些规则：
各目录键相同、每条消息有描述、占位符齐全。

## 目录的使用

Go core（`mygo/core/i18n`）读取 ARB 文件（即 JSON），用 mygo 的 `i18n` 包格式化 ICU 消息——
它按 Unicode CLDR 的复数规则实现 ICU MessageFormat（复数、序数、选择、数字与日期）；测试解析每条消息
并检查上条规则。转换后的文件（如其它目录格式）是构建产物，不得作为源码提交。

### 插件配置档案里的文字

插件配置档案（`core/profile`：镜像名称、简写的说明、须知）是唯一的例外：它们用两种语言写在所描述的数据旁边，
即 `Text{EN, ZH}`，Web 界面与安卓应用通过 HTTP 同时拿到两种语言，再按自己的设置选择。产品名称
（`Temurin`、`npmmirror`）只写一次。它们周围的一切，例如按钮与标题，桌面端在翻译目录里，Web 端在页面的字符串表里。

## 语言选择

语言设置为 `system`、`english` 或 `simplifiedChinese`。`system` 时按桌面区域匹配
可用目录，英文回退；所有中文区域都用简体中文。

## 文风

- 英文：标题与按钮用句首大写（"Add plugin" 而非 "Add Plugin"）；标签无句号，句子有句号；
  需进一步输入的动作用 "…"（"Browse…"）。
- 中文：全角标点（，。：？“”（）），中英文与数字间加空格（`安装 maven@3.9.16`、
  `已安装 2 个版本`），省略号用 `…`。

## 添加语言

1. 复制 `shared/i18n/app_en.arb` 为 `app_<区域>.arb`，设 `@@locale` 并去掉 `@`
   元数据。
2. 翻译每条消息；保留占位符与 ICU 语法。
3. 在语言设置中加入该语言（见
   [`architecture.md`](architecture.md#设置)）。
4. 跑测试。
