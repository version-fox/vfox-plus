# vfox-plus

[简体中文](README.zh-CN.md)

A graphical front end for [vfox](https://vfox.dev), the cross-platform version
manager, built with the [Material 3 Expressive](https://m3.material.io/) design
language.

[![Listed on Awesome MyGo](https://awesomemygo.dev/badge.svg)](https://awesomemygo.dev/apps/vfox-plus)

</div>

Documentation lives in [`docs/`](docs/en/user/index.md), by language and by
audience:

| | English | 简体中文 |
| --- | --- | --- |
| User guides | [docs/en/user/index.md](docs/en/user/index.md) | [docs/zh-CN/user/index.md](docs/zh-CN/user/index.md) |
| Developer specification | [docs/en/dev/architecture.md](docs/en/dev/architecture.md) | [docs/zh-CN/dev/architecture.md](docs/zh-CN/dev/architecture.md) |

Start with the [user guide](docs/en/user/index.md) ([简体中文](docs/zh-CN/user/index.md)):
what it does, [install](docs/en/user/install.md), [use](docs/en/user/using.md),
the [web interface](docs/en/user/remote.md), the [Android app](docs/en/user/android.md) and the
[gateway](docs/en/user/gateway.md) (Docker).
